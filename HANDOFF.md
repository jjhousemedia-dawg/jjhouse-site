## 1. What to do with this

The branch exists only in my sandbox, because a public clone is read-only without credentials. Two ways to get it onto your machine, both GUI:

**Zip route (simplest).**
1. Unzip `jjhouse-scroll-rebuild.zip` over `C:\Users\jjhou\jjhouse-site`, keeping folder structure. It only contains the 8 new or changed files, so nothing else is disturbed.
2. In GitHub Desktop: **Current Branch → New Branch**, call it `rebuild/scroll`.
3. The changes appear in the Changes tab. Commit, then **Publish branch**.
4. Vercel builds a preview URL automatically and posts it on the branch.

**Bundle route** if you ever want the real commit with its message: `jjhouse-scroll-rebuild.bundle`, applied with `git pull <path-to-bundle> rebuild/scroll`. Needs a terminal, so only if you feel like it.

**Nothing here goes near `main`.** `www.jj.house` stays exactly as it is until you merge.
